# docs/decisions

Working coordination records between Dev 1 and Dev 2: issues that need a joint decision
before they are applied to code, contracts or the finalized project documents.

- `phase0_coordination.md` — discrepancies and gaps found in Phase 0, each with a proposed
  resolution and a status (`PROPOSED` → `CONFIRMED` → `APPLIED`).

Final project decisions are recorded in `dev_docs/DECISIONS.md`; this folder only tracks items
until they are confirmed. Contracts that depend on an item reference it by ID (e.g. `P0-10`).
