# Phase 0 Coordination Items

Discrepancies and gaps found during Phase 0 that need a **joint** decision by Dev 1 and Dev 2.
Nothing here is resolved until both developers confirm it. Once confirmed, the outcome is applied in a
small PR to the affected file, recorded in `dev_docs/DECISIONS.md` if it is a project decision, and
logged in the roadmap decision log (roadmap Section 1).

`scenarios.md` is not modified by any item.

Status values: `PROPOSED` → `CONFIRMED` (both developers) → `APPLIED` (change merged).

**2026-09-30:** all items P0-01 to P0-17 were confirmed as proposed and recorded in `dev_docs/DECISIONS.md`
("Phase 0 Decisions"). P0-03 was first confirmed as local Docker Compose PostgreSQL, then changed the same day to **Neon PostgreSQL** (final).
